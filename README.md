# Онлайн-моніторинг трансформаторного масла

Моделювання теплового стану, вологовмісту, розчинених газів і діелектричних властивостей у MATLAB. Дані синтетичні; діагностичні пороги умовні, крім довідкових діапазонів RS за IEC 60422:2024.

## Запуск

Відкрийте папку проєкту в MATLAB (R2019b або новіший) і запустіть `main.m`. Параметри змінюються у `monitor_settings.m`. За замовчуванням моделюються 72 години з кроком 15 хвилин; цикл газоаналізатора — 1,5 години.

| `cfg.scenario` | Сценарій |
|---|---|
| 1 | Нормальна робота |
| 2 | Порушення охолодження |
| 3 | Надходження води |
| 4 | Додаткове газоутворення |
| 5 | Усі чотири порушення |
| 6 | Зміна електричних властивостей |

Для збереження рисунків у папку `figures/` встановіть `cfg.savePlots = true`. Пунктирні вертикальні лінії позначають початок заданих порушень, а не момент спрацювання попереджень.

## Файли

| Файл | Призначення |
|---|---|
| `main.m` | Запуск розрахунків, виведення результатів, побудова та збереження рисунків. |
| `monitor_settings.m` | Параметри, сценарії, часові інтервали та діагностичні межі. |
| `generate_demo_data.m` | Генерація синтетичних показань датчиків і заданих порушень. |
| `model_thermal.m` | Розрахунок температури масла, гарячої точки та температурного відхилення методом ode45. |
| `oil_properties_at_temp.m` | Інтерполяція табличних теплофізичних властивостей масла залежно від температури. |
| `simulate_moisture_exchange.m` | Моделювання обміну водою між маслом і паперовою ізоляцією для генерації даних. |
| `water_solubility.m` | Розрахунок температурної розчинності води. |
| `model_moisture.m` | Вологовміст, відносне насичення, добові середні та попередження. |
| `model_dga.m` | Концентрації семи газів, TDCG, газові співвідношення, швидкості зміни та попередження. |
| `model_oil_properties.m` | Теплофізичні й електричні характеристики, температурна корекція, коефіцієнт Kσ. |
| `evaluate_state.m` | Оцінювання чотирьох діагностичних каналів без інтегрального індексу. |
| `plot_thermal.m` | Графіки теплового стану та в’язкості (рис. 3.2). |
| `plot_moisture.m` | Графіки вологовмісту (рис. 3.3). |
| `plot_dga.m` | Графіки розчинених газів (рис. 3.4). |
| `plot_dielectric_online.m` | Графіки електричних характеристик (рис. 3.5). |
| `plot_diagnostics.m` | Підсумковий графік комплексного моніторингу (рис. 3.6). |
| `plot_oil_properties.m` | Додаткові графіки теплофізичних та електричних властивостей. |
| `format_time_axes.m` | Спільні межі часової осі та відступи графіків. |
| `mark_fault_start.m` | Позначення початку заданого порушення. |
| `README.md` | Інструкція запуску та опис файлів. |

Моделі демонструють обробку онлайн-вимірювань і не визначають залишковий ресурс масла. Зміна електропровідності не є моделлю швидкості хімічного старіння. Для оцінювання вологісного стану за IEC 60422 потрібні спостереження тривалістю щонайменше один місяць.
