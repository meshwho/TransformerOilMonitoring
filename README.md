# TransformerOilMonitoring

Навчальна MATLAB-система моніторингу стану трансформаторного масла.

## Запуск

Відкрийте кореневу папку репозиторію як Current Folder у MATLAB.

- У файлі monitor_settings.m виберіть сценарій (1–6).
- Запустіть main.m для моделювання та побудови графіків.

Спеціалізовані MATLAB Toolbox не потрібні. Модель використовує стандартну функцію ode45.

## Модель теплового стану (підрозділ 3.2)

- model_thermal.m: нелінійне рівняння температури верхніх шарів масла з урахуванням відносної в'язкості (формула 3.13 з МАН 2024 року).
- oil_properties_at_temp.m: єдина функція інтерполяції теплофізичних характеристик масла за таблицями 3.3 і 3.5 з МАН.
- Динаміка гарячої точки моделюється окремими диференціальними рівняннями за IEC 60076-7.
- generate_demo_data.m: при порушенні охолодження змінюється множник теплообміну; температура з'являється як результат розв'язку рівняння, а не довільна надбавка до показання датчика.
- plot_thermal.m: розрахункова і виміряна температури, їх різниця, а також зміна в'язкості масла.

У нормальному режимі прогноз температури будується лише за навантаженням та температурою середовища. Виміряну температуру використовуємо тільки для порівняння з прогнозом і оцінки властивостей масла.

## Межі застосування

**Всі дані синтетичні.** Коефіцієнти теплової моделі, показники гарячої точки і пороги тривог демонстраційні; вони не визначені за паспортом конкретного трансформатора. Модель не валідована для промислової діагностики.

Лише в'язкість впливає назад на рівняння теплового балансу. Густина, теплоємність, теплопровідність та коефіцієнт об'ємного розширення розраховуються за температурою, але окремо не входять у тепловий баланс. Для їх урахування потрібні додаткові конструктивні дані.

Коефіцієнт coolingEfficiency є введеним для сценарію умовним множником, а не частиною оригінальної формули МАН.

Моделі DGA та оцінки лабораторних показників у цьому оновленні не змінювалися. Електричні характеристики масла поки обчислюються за спрощеною демонстраційною температурною моделлю.

## Джерела

- МАН (2024): «Дослідження можливості розміщення трансформатора під землею з дотриманням теплового режиму», формула (3.13), таблиці 3.3 і 3.5.
- IEC 60076-7:2018: Loading guide for mineral-oil-immersed power transformers.

## Модель вологовмісту (підрозділ 3.3)

- water_solubility.m: розчинність води залежно від температури за формулою 3.5.
- generate_demo_data.m: генерує синтетичні вимірювання активності води aw і температури, а не передає готове значення ppm.
- model_moisture.m: розраховує відносне насичення, вміст води в мг/кг, середнє за 24 години та добову зміну середнього.
- plot_moisture.m: показує поточний і усереднений вологовміст, відносне насичення та добову зміну.

При кроці 0,25 год середнє використовує 96 вимірювань. Воно доступне після 24 годин; перша добова зміна - після 48 годин. Недоступні значення позначаються NaN. На відміну від реального MHT410, який оновлює Daily ROC кожні 12 годин, навчальна модель перераховує його кожні 15 хвилин.

Умовні коефіцієнти C0 = 16,97·10^6 мг/кг і B = 3777 К відповідають одному зразку мінерального масла з таблиці II CIGRE 349. Це не універсальні значення і не фірмові коефіцієнти Vaisala.

Сценарій зростання вологовмісту синтетичний: фізичне перенесення води між маслом і целюлозою не моделюється.

Джерела: CIGRE Technical Brochure 349 (2008), таблиця II; Vaisala MHT410 User Guide (24-годинне середнє та Daily ROC).
